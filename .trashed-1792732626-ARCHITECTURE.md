# FOOT AI NEWS — Architecture technique (v1)

Ce document couvre la **version 1** définie dans le cahier des charges (section 42) : interface, tableau de bord, API football, matchs, scores, événements, actualités, IA de génération de texte, génération de visuels, aperçu, connexion Facebook, publication manuelle. L'automatisation complète, la programmation, les notifications et le multi-pages sont prévus dans le schéma mais pas activés en v1.

---

## 1. Stack recommandée

| Couche | Choix | Raison |
|---|---|---|
| Frontend | Next.js (React) + Tailwind | SSR pour le SEO des actualités, bon support mobile |
| Backend | Node.js + Express (ou routes API Next.js) | Simplicité, écosystème mature pour Meta Graph API |
| Base de données | PostgreSQL + Prisma ORM | Relationnel, adapté aux relations matchs/événements/publications |
| File d'attente | Redis + BullMQ | Détection d'événements → tâches de publication asynchrones |
| IA texte | API Claude (Anthropic) | Génération de texte, résumés, reformulation |
| Génération d'images | API image (à connecter) | Visuels de scores/actualités |
| Données football | Fournisseur externe (ex. API-Football, SportRadar) | **SERVICE À CONNECTER** — clé API côté serveur uniquement |
| Facebook | Meta Graph API + OAuth officiel | Jamais de mot de passe stocké |

## 5. Détection d'événements → publication (logique clé)

```ts
// services/eventDetector.ts
async function pollMatch(matchId: string) {
  const liveData = await footballProvider.getMatch(matchId); // fournisseur externe
  const knownEvents = await db.matchEvent.findMany({ where: { matchId } });

  const newEvents = liveData.events.filter(
    e => !knownEvents.some(k => k.type === e.type && k.minute === e.minute && k.playerId === e.playerId)
  );

  for (const event of newEvents) {
    await db.matchEvent.create({ data: { ...event, matchId, priority: getPriority(event.type) } });

    const rule = await db.automationRule.findFirst({ where: { triggerType: event.type, active: true } });
    if (rule) await queue.add('generate-post', { eventId: event.id, action: rule.action });
  }
}

function getPriority(type: string) {
  if (['goal', 'red_card', 'penalty', 'full_time'].includes(type)) return 'urgent';
  if (['yellow_card', 'substitution', 'lineup', 'injury'].includes(type)) return 'important';
  return 'normal';
}
```

Règle stricte : ce service ne fait **que lire** ce que renvoie le fournisseur de données. Il ne complète, n'invente et n'infère jamais un score, un buteur ou une minute.

## 6. Génération de texte IA (prompt système type)

```ts
// services/aiGenerator.ts
const SYSTEM_PROMPT = `
Tu es le rédacteur de FOOT AI NEWS, un média football professionnel.
Règles strictes :
- Utilise UNIQUEMENT les données fournies dans le message.
- N'invente jamais un score, un buteur, une minute, un transfert, une blessure,
  un carton ou une composition qui ne figure pas dans les données.
- Si une information manque, ne la mentionne pas plutôt que de la déduire.
- Style : direct, factuel, ton media sportif professionnel, texte court.
- Termine par 2 à 4 hashtags pertinents.
`;

async function generatePost(eventData: object, style: string) {
  const response = await anthropic.messages.create({
    model: "claude-sonnet-4-6",
    max_tokens: 300,
    system: SYSTEM_PROMPT,
    messages: [{
      role: "user",
      content: `Style demandé : ${style}\nDonnées vérifiées :\n${JSON.stringify(eventData)}`
    }]
  });
  return response.content[0].text;
}
```

## 7. Connexion Facebook (Meta Graph API)

- OAuth officiel Meta (`facebook-login for business`), jamais de mot de passe stocké.
- Le token d'accès de page est chiffré en base (`FacebookPage.accessToken`) et n'est jamais renvoyé au frontend.
- Publication texte : `POST /{page-id}/feed`
- Publication avec image : `POST /{page-id}/photos`
- Programmation : possible uniquement si le token a le scope `pages_manage_posts` et que l'API le permet (`scheduled_publish_time`).

## 8. Anti-spam (section 17 du cahier des charges)

Vérification avant chaque publication :

```ts
async function canPublish(pageId: string) {
  const settings = await db.automationSettings.findFirst();
  const lastHour = await db.post.count({
    where: { facebookPageId: pageId, publishedAt: { gte: subHours(now, 1) }, status: 'published' }
  });
  const lastPost = await db.post.findFirst({
    where: { facebookPageId: pageId, status: 'published' }, orderBy: { publishedAt: 'desc' }
  });

  if (lastHour >= settings.maxPostsPerHour) return false;
  if (lastPost && differenceInSeconds(now, lastPost.publishedAt) < settings.minDelaySeconds) return false;
  return true;
}
```

## 11. Points de vigilance sécurité

- Toutes les clés API : variables d'environnement serveur uniquement.
- Rate limiting sur les routes publiques (`/api/news`, `/api/matches`).
- Validation stricte des payloads (zod) avant tout appel IA ou publication.
- Le mode démonstration (section 41) doit avoir un flag `isDemo: true` bloquant explicitement toute route de publication Facebook.
