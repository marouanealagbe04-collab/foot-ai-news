# FOOT AI NEWS — Brief de reprise pour Claude Code

Ce dossier contient tout ce qui a été préparé sur Claude.ai avant de passer
à Claude Code pour l'implémentation réelle (fichiers exécutables, base de
données, tests d'intégration, déploiement).

## Ce qui existe déjà dans ce dossier

- `ARCHITECTURE.md` — schéma de base de données complet (Prisma), liste des
  endpoints API, structure de projet recommandée, logique anti-spam, prompt
  système IA, intégration Facebook, ordre de construction en 2 étapes.
- `prototype/foot-ai-news.html` — maquette visuelle statique (accueil,
  matchs live, actualités, tableau de bord avec panneau IA). Sert de
  référence de design, pas de code à réutiliser tel quel dans le vrai
  frontend Next.js.
- `packages-football-provider/` — module TypeScript **fonctionnel et
  testé** : fournisseur de données API-Football, fournisseur mock, factory
  de sélection de fournisseur, détecteur d'événements avec priorités et
  idempotence. Tests Vitest inclus (`npm test`), aucune clé API requise
  pour les faire tourner. À déplacer tel quel dans le futur
  `apps/api/src/services/` du projet réel (voir structure dans
  `ARCHITECTURE.md`, section 2).

Puis étape 2 : automatisation complète, programmation, notifications,
multi-pages Facebook, statistiques avancées.

## Contraintes non négociables à respecter tout au long du projet

- **Ne jamais inventer une donnée football.** Un champ absent de l'API
  devient `null`, jamais une valeur déduite ou estimée. Le
  `footballProvider` fourni respecte déjà cette règle strictement.
- **Le mode démonstration ne doit jamais publier réellement sur Facebook**,
  même si l'automatisation est activée par erreur.
- **Aucune clé API ou secret dans le code ou le repo** — tout passe par des
  variables d'environnement côté serveur uniquement (`.env`, jamais commité).
- **Le fournisseur de données football doit rester interchangeable** :
  toute nouvelle intégration (ex. Sportmonks) passe par l'interface
  `FootballProvider` déjà définie, sans toucher au reste de l'app.
